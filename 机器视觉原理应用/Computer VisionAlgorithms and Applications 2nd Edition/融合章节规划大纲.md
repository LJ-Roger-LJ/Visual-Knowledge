## 融合章节大纲（按书本顺序）

### 第1章 绪论（Original：Introduction）

- 原书对应：书页 1–32 / PDF 27–58
- 本章核心简述：什么是计算机视觉、简史、全书导览、示例课表、记号约定与延伸阅读。前言把课表用法指向本节 1.4 与表 1.1。

### 第2章 图像形成（Original：Image formation）

- 原书对应：书页 33–106 / PDF 59–132
- 本章核心简述：2D/3D 几何图元与变换、三维旋转、3D→2D 投影、镜头畸变；光度成像（光照、反射与明暗、光学）；数字相机（采样与混叠、颜色、压缩）。这是后文几何、标定、立体与 Shape from X 的共用底座。

### 第3章 图像处理（Original：Image processing）

- 原书对应：书页 107–190 / PDF 133–216
- 本章核心简述：点运算（像素/颜色变换、合成与抠图、直方图均衡、影调调整）；线性滤波与可分离核、带通与方向滤波；非线性滤波、双边滤波、二值形态学；傅里叶变换；金字塔与小波、插值与抽稀、图像融合；参数几何变换与网格变形、特征变形。

### 第4章 模型拟合与优化（Original：Model fitting and optimization）

- 原书对应：书页 191–234 / PDF 217–260
- 本章核心简述：散乱数据插值（径向基、过拟合与欠拟合、稳健拟合）；变分方法与正则化、离散能量、全变分、双边求解器、交互着色；马尔可夫随机场(MRF)与条件随机场(CRF)、交互分割。为后文立体、分割与着色提供能量/图模型框架。

### 第5章 深度学习（Original：Deep Learning）

- 原书对应：书页 235–342 / PDF 261–368
- 本章核心简述：监督学习（近邻、贝叶斯分类、逻辑回归、支持向量机、决策树与森林）；无监督学习（聚类、K 均值与高斯混合、主成分分析、流形学习、半监督）；深度网络（权重与层、激活、正则与归一化、损失、反向传播、训练）；卷积网络（池化、手写数字、网络结构、模型库、可视化、对抗样本、自监督）；更复杂模型（三维卷积、循环网络、Transformer、生成模型）。前言明确：后续多章会反复调用本章。

### 第6章 视觉识别（Original：Recognition）

- 原书对应：书页 343–416 / PDF 369–442
- 本章核心简述：实例识别；图像分类（特征法与深度网络、视觉相似检索、人脸识别）；物体检测（人脸、行人、通用检测）；语义分割、实例分割、全景分割、姿态估计、智能修图；视频理解；视觉与语言。前言：本章已前移，不依赖第7章特征链路。

### 第7章 特征检测与匹配（Original：Feature detection and matching）

- 原书对应：书页 417–500 / PDF 443–526
- 本章核心简述：点与块（检测器、描述子、匹配、大规模检索、特征跟踪、表演驱动动画）；边缘与轮廓、边缘编辑；轮廓跟踪（蛇模型与智能剪刀、水平集、转描）；直线、霍夫变换与消失点；分割（图方法、均值漂移、归一化割）。为第8章拼接与第11章运动恢复结构提供对应点。

### 第8章 图像对齐与拼接（Original：Image alignment and stitching）

- 原书对应：书页 501–554 / PDF 527–580
- 本章核心简述：成对对齐（最小二乘、迭代、稳健最小二乘与 RANSAC、三维对齐、拼贴摄影）；图像拼接（参数运动、白板/文档扫描、旋转全景、补缝、柱面与球面坐标）；全局对齐（光束法平差、去视差、识别全景）；合成（投影面选择、去鬼影、照片蒙太奇、融合）。

### 第9章 运动估计（Original：Motion estimation）

- 原书对应：书页 555–606 / PDF 581–632
- 本章核心简述：平移对齐（分层、傅里叶、增量精化）；参数运动（视频稳定、样条运动、医学配准）；光流（含深度学习、滚动快门抖动去除、多帧、视频去噪）；分层运动（插帧、透明层与反射、视频目标分割与跟踪）。

### 第10章 计算摄影（Original：Computational photography）

- 原书对应：书页 607–680 / PDF 633–706
- 本章核心简述：光度标定（辐射响应、噪声水平、渐晕、光学模糊）；高动态范围成像与色调映射、闪光摄影；超分辨率、去噪与去模糊、去马赛克、镜头虚化；抠图与合成（蓝幕、自然抠图、优化抠图、烟/影/闪光、视频抠图）；纹理分析与合成、孔洞填充、非真实感绘制、神经风格迁移与语义图像合成。

### 第11章 运动恢复结构与同时定位建图（Original：Structure from motion and SLAM）

- 原书对应：书页 681–748 / PDF 707–774
- 本章核心简述：几何内参标定（消失点、单视测量、旋转运动、径向畸变）；位姿估计（线性/非线性、位置识别、三角化）；两帧运动恢复结构（八点/七点/五点、特殊运动、射影重建、自标定、视点变形）；多帧运动恢复结构（分解、光束法平差、稀疏性、匹配移动、互联网照片重建、全局 SfM）；同时定位与建图(SLAM)，以及自主导航与手机增强现实。前言点名 SLAM 与视觉惯性里程计(VIO)。

### 第12章 深度估计（Original：Depth estimation）

- 原书对应：书页 749–804 / PDF 775–830
- 本章核心简述：对极几何、立体校正、平面扫描；稀疏对应与三维曲线轮廓；稠密对应与相似度；局部方法与亚像素、立体头部跟踪；全局优化（动态规划、基于分割、Z-keying）；深度网络立体匹配；多视立体、场景流、体与表面重建、轮廓剪影；单目深度估计。

### 第13章 三维重建（Original：3D reconstruction）

- 原书对应：书页 805–860 / PDF 831–886
- 本章核心简述：Shape from X（明暗与光度立体、纹理、聚焦）；三维扫描与多片距离数据融合、数字遗产；表面表示（插值、简化、几何图像）；基于点的表示；体表示与隐式曲面/水平集；基于模型的重建（建筑、人脸建模与动画、人体）；纹理贴图、反照率与双向反射分布函数(BRDF)、三维模型采集。

### 第14章 基于图像的绘制（Original：Image-based rendering）

- 原书对应：书页 861–914 / PDF 887–940
- 本章核心简述：视点插值、视点相关纹理、Photo Tourism；分层深度图、精灵与图层、三维摄影；光场与 Lumigraph、非结构化 Lumigraph、表面光场、同心镶嵌、合成重对焦；环境蒙版与更高维光场；基于视频的绘制（动画、视频纹理、三维/自由视点视频、漫游）；**神经绘制(Neural Rendering)是 14.6 节，不是独立第15章**。

### 第15章 结语（Original：Conclusion）

- 原书对应：书页 915–918 / PDF 941–944
- 本章核心简述：全书收束。目录无细分节，篇幅约 4 页，不新开算法专节。

### 附录A 线性代数与数值方法（Original：Linear algebra and numerical techniques）

- 原书对应：书页 919–938 / PDF 945–964
- 本章核心简述：矩阵分解（奇异值、特征值、QR、Cholesky）；线性最小二乘与总体最小二乘；非线性最小二乘；稀疏直接法与变量重排；迭代法（共轭梯度、预条件、多重网格）。正文章引用线性代数时只给简写解释，公式细节放本附录。

### 附录B 贝叶斯建模与推断（Original：Bayesian modeling and inference）

- 原书对应：书页 939–952 / PDF 965–978
- 本章核心简述：估计理论；最大似然与最小二乘；稳健统计；先验模型与贝叶斯推断；马尔可夫随机场；不确定性估计。与第4章 MRF、第5章学习互补，不在正文章重写公式推导。

### 附录C 补充材料（Original：Supplementary material）

- 原书对应：书页 953–972 / PDF 979–998
- 本章核心简述：数据集与基准、软件库、幻灯与课程资源。前言把习题与小项目的数据/库入口指向本附录。

参考文献（书页 973–1178 / PDF 999–1204）与索引（书页 1179 起 / PDF 1205 起）不写笔记。

## 跨章节前置说明

- **第1章**：全书地图和课表只定位，算法细节按后续对应章写。
- **第2章**：几何、光度与相机模型是后文共用底座；标定、运动恢复结构、立体、Shape from X 不在本章展开。
- **第3章**：抠图与融合只作处理算子；完整抠图与高动态范围合成留第10章，拼接融合留第8章。
- **第4章**：马尔可夫随机场与能量只讲框架；立体全局优化留第12章，分割细节与第7.5节分工。
- **第5章**：只建学习与网络工具箱；分类、检测、分割应用留第6章，光流、立体、神经绘制分别留第9、12、14章。
- **第6章**：按前言，不回头补第7章特征工程；人脸检测与通用检测只在识别语境下写。
- **第7章**：特征是对齐与运动恢复结构的输入；RANSAC 全景与光束法平差留第8、11章；消失点在第11.1.1节还要用于标定。
- **第8章**：成对与全局对齐止于拼接；多视三维与同时定位建图留第11章。
- **第9章**：二维运动与光流；场景流留第12.7.1节，三维跟踪留第13章。
