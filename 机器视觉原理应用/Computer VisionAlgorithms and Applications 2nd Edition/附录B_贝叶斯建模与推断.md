# 附录 B 贝叶斯建模与推断

来源：Szeliski《Computer Vision: Algorithms and Applications》第二版电子终稿附录 B；书页 939–952 / PDF 965–978。与第4章 MRF、第5章学习互补，不在正文章重写推导。

## 本章总览

视觉多是逆问题：已知图像，估姿态、形状、参数。有时能写出闭式（如相机矩阵 DLT，(B.1)–(B.4)），但测量有噪声时，要问「这套方程是不是该最小化的那个」。本附录从估计理论讲到似然、稳健统计、先验与贝叶斯、MRF、不确定度。

## 核心知识点

### 估计与最大似然

先建前向测量模型（图形学是前向，视觉是逆向）。高斯噪声下，最大似然(ML)就是最小二乘——第4、5、8、11章的 $E_D$ 由此来。若噪声不是高斯，平方残差就不是 ML。

🔑 关键速记：最小二乘默认高斯；模型错了，闭式线性解也可以不是「最好」。

📚 基础补充：【最大似然 ML 与最大后验 MAP】

- 是什么：最大似然(maximum likelihood, ML)只问「哪套参数最能解释我看见的数据」。最大后验(maximum a posteriori, MAP)再乘上先验 $p(x)$：既要解释数据，又要像我们事先认为合理的解。
- 为什么要用它：纯 ML 在数据少或噪声大时会过拟合。MAP 的先验就是第4章平滑项的概率来源。高斯噪声下 ML = 最小二乘。
- 直观理解：听见一声响，ML 说「最像打雷」；MAP 还记得「这是室内」，于是更可能改判「有人摔了东西」。无先验时 MAP 退回 ML。MAP 取的是后验峰，不一定比后验均值更稳。

- 和本附录的关系：下一节贝叶斯公式把 $p(x|y)\propto p(y|x)p(x)$ 写清楚。第4章能量 $E_D+E_P$ 就是负对数后验。

🔑 关键速记：ML 只拟合数据；MAP = 数据 × 先验；高斯 ML 就是最小二乘。

### 稳健统计

外点用 $\rho$ 而不是 $r^2$，即 M-估计；IRLS 是算法。尺度可用 MAD。与第4.1.3节 Barron 损失、第8章 RANSAC 分工：这里讲概率含义，RANSAC 讲怎么找内点核。

👉 完整深度讲解见第4章与第8章。

🔑 关键速记：稳健损失 = 非高斯似然的负对数。

📚 基础补充：【稳健统计为什么能抗噪声】

- 是什么：稳健统计(robust statistics)不让少数极端观测主宰估计。M-估计把 $r^2$ 换成增长更慢的 $\rho(|r|)$；RANSAC 则先丢掉外点再拟合。
- 为什么要用它：高斯平方对外点极度敏感（第4章最小二乘图）。匹配错误、高光、行人走进全景，都会变成大红残差。
- 直观理解：班级平均分被一个 0 分拉垮；改用中位数或「大误差封顶」的 $\rho$，成绩单才代表大多数。IRLS 是算法：根据当前残差改每个点的权重，再做一次加权最小二乘，循环。尺度（多宽算内点）可用 MAD。RANSAC 负责「里面有骗子」的离散清洗，M-估计负责「多数轻微脏」的连续降权。

- 和本附录的关系：概率上，$\rho$ 对应比高斯更重尾的似然的负对数。第4章 Barron 损失、第8章 IRLS 是同一工具在视觉里的用法。

🔑 关键速记：平方怕野点；$\rho$ 把大残差封顶，RANSAC 先把骗子请出去。

### 先验、贝叶斯、MRF

贝叶斯：$p(x|y)\propto p(y|x)p(x)$，MAP 能量 = 数据项 + 先验项，即第4章 (4.33)–(4.35)。MRF 把先验写成邻域势，推断用图割、LBP 等（B.5）。MAP 取峰，不一定比后验均值稳。不确定度（B.6）给后续融合用。

👉 MRF/CRF 框架完整深度讲解见第4章。

🔑 关键速记：先验不是「平滑好看」，是 $p(x)$；网格上就是 MRF。

📚 基础补充：【贝叶斯公式的直观理解】

- 是什么：贝叶斯(Bayes)公式说，看见数据 $y$ 之后，对未知 $x$ 的信念，等于「$x$ 能多好地解释 $y$」（似然）乘上「没看数据前你有多相信 $x$」（先验），再归一化。写作 $p(x|y)\propto p(y|x)p(x)$。
- 为什么要用它：视觉是逆问题，很多 $x$ 都能生成相似的图。只靠数据会有无穷多解，先验把解拉回合理区域（平滑的深度、稀疏的梯度、合理的人脸形）。
- 直观理解：医生看病：化验是似然，发病率是先验，诊断是后验。像素去噪：观测图是 $y$，干净图是 $x$，邻域相似是先验。负对数之后，乘积变成第4章的能量相加。MRF 只是把 $p(x)$ 写成「邻居势之和」的一种先验。

公式人话翻译：(4.33) / 本附录同一式：输入似然与先验，输出后验（差一个不依赖 $x$ 的 $p(y)$）。MAP 取让后验最大的 $x$。

- 和本附录的关系：下面「似然→后验→MAP」流程图就是同一句话。不确定度给融合用，不必每次只留一个点估计。

🔑 关键速记：后验 ∝ 似然 × 先验；能量相加是负对数后的同一句话。

## 本章要点总结

- 逆问题要建误差模型，不能只代数消元。
- 高斯 → 最小二乘；外点 → 稳健 / RANSAC。
- 贝叶斯 MAP = 第4章能量；MRF 推断与不确定度在本附录收口。
