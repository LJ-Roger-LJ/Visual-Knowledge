### 各自侧重

- **文档1**：安装与跨平台环境、文件/摄像头/GUI 与面向对象外壳、把图像处理嵌进 Cameo、深度与前景分割、Haar 人脸检测与识别、描述符检索与以图搜图、自定义物体检测器、视频跟踪、相机模型与增强现实、ANN/DNN（手写数字、性别与年龄）。图像处理基础（滤波、形态学、直方图）不设专章，多挤在第3章。
- **文档2**：Mat/I/O、颜色与几何变换、直方图与模板匹配、滤波与边缘、形态学、轮廓/形状/QR、频域/积分图/分割/修复、角点与 SIFT/SURF/ORB、单目/双目标定、视频分析、传统机器学习五类算法与 DNN 应用实例。无人脸专章、无 AR 专章、无自定义检测器专章。

### 融合思路

不以某一本书的目录顺序硬搬。主线按 OpenCV4 常见知识链：

安装与模块 → 数据与 GUI → 基本图像操作 → 滤波/边缘 → 形态学 → 直方图/匹配 → 轮廓与形状 → 频域/分割/修复 → 特征匹配 → 深度/标定 → 相机/AR → 人脸 → 视频跟踪 → 检测器与传统 ML → 神经网络。

- **合并重复**：安装、I/O、滤波边缘、特征匹配、跟踪、DNN。
- **互补缺失**：文档1补人脸、自定义检测器、AR、ANN；文档2补形态学专章、直方图专章、QR、积分图、相机标定细节、传统 ML 五类算法。
- **粒度**：对齐原书主章节，不拆到 1.2.3 级。文档1第3章（颜色+滤波+轮廓混写）拆入多个融合章，页码标注「非整章、与其他融合章共享」。
- **语言**：后续笔记只做概念/API 对照，不写可运行工程代码。
- **本阶段约束**：未读正文章节；OCR 已按目录上下文校正常用词（如 YAML、Farneback、双目标定），生成笔记前以该节原文为准。

第10–11章、第14–15章按计划默认**不合并**。
